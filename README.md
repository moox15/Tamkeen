# 🎓 منصة تمكّن التعليمية (Tamkeen Academy Platform)

منصة تعليمية وإدارية متكاملة مصممة لتقديم تجربة تعليمية فردية متميزة عبر الإنترنت، وإدارة الطلاب، الحصص، الجداول، الواجبات، الاشتراكات والمدفوعات.

---

## 🚀 المميزات الرئيسية (Features)

### 👑 لوحة تحكم الإدارة (Admin Dashboard)
* **إدارة الطلاب:** إضافة طلاب جدد، تفعيل/تعطيل الحسابات، إعادة تعيين كلمات المرور، وحذف الحسابات.
* **إدارة المعلمين:** إضافة المعلمين وتخصيص التخصصات والملاحظات.
* **المواد الدراسية والباقات:** إضافة وتعديل وحذف المواد الدراسية وباقات الحصص بمرونة تامة.
* **الجدول والحصص:** جدولة الحصص الفردية، ربطها بروابط اللقاءات (Zoom/Meet)، وتسجيل الحضور والغياب.
* **الواجبات والتصحيح:** إنشاء واجبات بأنواع أسئلة متعددة، تصحيح إجابات الطلاب، رصد الدرجات، وكتابة ملاحظات المعلم التوجيهية.
* **الاشتراكات والمدفوعات:** تتبع باقات الطلاب، الحصص المتبقية والمكتملة، وفواتير السداد.
* **الأمان وسجل العمليات:** سجل تدقيق (Audit Logs) لجميع الإجراءات التي تتم على المنصة.

### 🎒 بوابة الطالب (Student Portal)
* **لوحة المتابعة:** عرض الحصص القادمة، رصيد الباقة الحالي، ومعدل الحضور.
* **الجدول الدراسي:** استعراض مواعيد الحصص وروابط الاجتماعات المباشرة.
* **الواجبات والتقييمات:** حل الأسئلة التفاعلية وتسليمها، وعرض الدرجات وملاحظات المعلم بعد التصحيح.
* **متابعة الإنجاز:** رسوم بيانية تفاعلية لمعدلات الأداء والدرجات في كل مادة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Frontend:** React 18, Vite, React Router 6, TailwindCSS, Lucide Icons, Chart.js.
* **Backend:** Node.js, Express, Better-SQLite3 (قاعدة بيانات خفيفة وسريعة ذات أداء فائق).
* **Security & Sessions:** Express-Session (SQLite Store), CSRF Protection, Bcrypt Password Hashing, Rate Limiting.

## 📦 طريقة التثبيت والتشغيل المحلي (Setup & Run)

### 1. المتطلبات:
* [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)

### 2. تثبيت الحزم (Dependencies):
```bash
# تثبيت حزم السيرفر
cd server
npm install

# تثبيت حزم الواجهة
cd ../client
npm install
cd ..
```

### 3. تشغيل المنصة:

* **تشغيل السيرفر (Backend):**
  ```bash
  npm run dev:server
  ```
  *(يعمل على http://localhost:3001)*

* **تشغيل واجهة المستخدم (Frontend):**
  ```bash
  npm run dev:client
  ```
  *(تعمل على http://localhost:5173)*
